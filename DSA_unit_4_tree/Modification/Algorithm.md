## Algorithm:

Step 1: Start the program.

Step 2: Create a node structure containing the student's roll number, name, and pointers to the left and right child nodes.

Step 3: Initialize the BST as empty.

Step 4: Display the following menu:

Insert student record

Search student record

Update student record

Delete student record

Display all student records

Exit

Step 5: Enter the user's choice.

Step 6: Perform the selected operation.

Insertion: Enter the student's roll number and name. Insert the record into the correct position in the BST.

Searching: Enter the roll number and search for the student record. Display the details if found.

Updating: Enter the roll number, search for the record, and update the student's name if the record exists.

Deletion: Enter the roll number and delete the corresponding student record from the BST.

Display: Perform inorder traversal (Left → Root → Right) to display student records in ascending order of roll numbers.

Step 7: Display an appropriate message after each operation.

Step 8: Return to the menu if the user does not select Exit.

Step 9: Stop the program when the user selects Exit.
