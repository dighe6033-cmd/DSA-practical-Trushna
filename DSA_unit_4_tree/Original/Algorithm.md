## Algorithm:

Step 1: Start the program.

Step 2: Define a node structure containing the student roll number and pointers to the left and right child nodes.

Step 3: Create an empty Binary Search Tree.

Step 4: Display a menu with the following operations:

Insert a roll number.

Search for a roll number.

Display all roll numbers.

Exit

Step 5: If the user selects insertion, enter a roll number and insert it into the correct position in the BST.

Step 6: If the user selects searching, enter the roll number to be searched. Compare it with the root node and continue searching in the left or right subtree.

Step 7: If the user selects inorder display, traverse the BST in the order Left → Root → Right.

Step 8: Display the roll numbers in ascending order.

Step 9: Repeat the menu until the user selects Exit.

Step 10: Stop the program.
