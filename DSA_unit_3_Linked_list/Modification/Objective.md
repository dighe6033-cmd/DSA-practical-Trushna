## Objectives:
 
1.To understand the concept and working of a doubly linked list.

2.To perform basic operations such as insertion, traversal, searching, updating, and deletion.

3.To store grocery item names and quantities dynamically using linked list nodes.

4.To understand the use of next and prev pointers for connecting nodes in both directions.

5.To develop a menu-driven application using C++ functions, loops, and conditional statements.

6.To understand dynamic memory allocation and deallocation in C++.
